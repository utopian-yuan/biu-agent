# 材料工作台

在仓库根目录运行 `uv run python -m examples.tickets.app`，打开 [中文工作台](http://127.0.0.1:8765/)。点击「注册账号」，注册成功后用密码登录。可以在聊天框切换模型，在导航栏配置智能体、技能、工具和 MCP 连接。模型服务与 MCP 的访问密钥由本机服务端保存。

| 想改哪一处 | 从哪里开始 |
| --- | --- |
| 原文、目录和段号 | [三份虚构原文](data) · [来源适配](corpus.py) |
| 权限、工具、技能和每轮上下文 | [工作台装配](workspace.py) |
| 模型、智能体与持久化配置 | [配置注册表](config.py) |
| 首次设置口令与登录 | [账号入口](accounts.py) |
| 离线模型怎样发起工具调用 | [教学模型](teaching_model.py) |

跟着[材料工作台实操](../../tutorials/00-material-workspace/README.md)用同一问题对比两个权限范围。
