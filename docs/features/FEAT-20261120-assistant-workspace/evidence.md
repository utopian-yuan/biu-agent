| 输入或变化 | 存储与界面上观察到的结果 |
| --- | --- |
| 首次问两种物料，再追问「那导向牌呢？」 | 上下文摘要从 0 条历史问题变为 1 条，重新生成首问时回到 0 条 |

| 在临时副本中修改 R1 原文 | 旧引用返回版本已变更，新生成的回答引向修改后的段落 |

| 收窄一个智能体的授权 | 该智能体旧范围的历史、原文、重新生成均停止返回内容，其他智能体的会话仍可打开 |

开发中发现教学模型的归纳语句可能超出只含验收文件时的可见事实，已改为按实际读取的验收段落归纳，并加入「仅验收说明」回归。[测试用例](../../../tests/test_material_workspace.py)

## E4 · 选定的模型与 MCP 真正收到什么

本机临时运行一个兼容模型协议的测试服务和一个 Streamable HTTP MCP 服务。MCP 声明两个只读工具、一个模拟修改工具。在智能体中只绑定其中一个只读工具。测试服务实际收到所选模型标识 `catalog-example` 的两次模型请求；MCP 实际收到一次 `batch_number` 调用。未勾选的只读工具和模拟修改工具均未出现在模型收到的工具清单。答复包含测试服务返回的虚构批次 MX-07。[本机协议试验](../../../tests/test_material_connections.py)
