# 设计

聊天为默认工作区。左栏包含新对话、历史和配置入口，顶部选择智能体，输入框下方切换模型，回答操作紧跟每条回答。管理页复用工作台导航。用户首次登录可查看分步导览，每一步对应一个可操作的页面。

独立部署的用户在登录页注册自己的账号，再凭用户名和密码登录。服务端验证口令摘要并签发可注销的会话，后端按当前账号及智能体的授权读取教程材料。宿主嵌入沿用自身身份。旧数据保留原归属。已有业务回执不会因删除对话或重新生成而消失。

对话标题、删除状态和互斥反馈持久化到 SQLite。重新生成绑定原问题及此前上下文，保留原回答和原操作。服务端校验模型、技能、工具、MCP 与智能体设置，每一轮发起时解析实际配置。MCP 首版接入 Streamable HTTP，只注册明确标记为只读并已选中的远端工具。业务写入继续使用可确认的动作处理器。

公开交互参考 [QwenPaw 控制台](https://github.com/agentscope-ai/QwenPaw/tree/main/console) 和 [WeKnora 首次引导](https://github.com/Tencent/WeKnora/blob/main/frontend/src/components/NewUserGuide.vue)。工作台界面、说明、图形及业务样本独立编写。

素材库登记三份虚构文件。用户随问题发送的文件进入该对话的附件目录。模型先看授权目录，再按段读取。工具结果按轮收集来源 ID、段号与版本，界面按真实读取记录展示原文入口。服务端负责鉴权、保留历史预算、校验引文和配置生效时机。撤销授权时提升受影响智能体的权限版本。这些旧对话停止提供内容，新对话按新范围建立上下文。部署级授权上限变更会更新安装实例的权限版本。


## 实际的数据流

1. 本地账号校验后签发有效期一天的 HttpOnly Cookie。每次修改配置或对话均核对同源请求，工作台 API 同时核对 CSRF 令牌。
2. 建立会话时绑定账号、智能体、当前权限版本和默认模型。每轮从所选模型、提示词、可见资料、已启用技能和工具开始。仅将既往问题用于指代理解。历史上限为六轮、问题总预算 12000 字符。每次重新生成使用原问题之前的历史截面。
3. 目录和搜索提供定位信息，段落读取与 Shell 文本处理共用同一授权原文入口。单次返回通过长度检查后才登记来源。每次模型请求、工具调用和回答交付前核对当前授权。回答中的出处必须属于本轮读取记录，校验通过才向界面发布正文。
4. 成功轮次保存回答、实际模型名、原文索引和上下文摘要。点击出处时再次核对账号、智能体权限、轮次和文件当前版本。权限收窄影响对应智能体，普通的标题或技能文字调整保留既有历史。配置保存使用版本号防止覆盖并发编辑。
5. 注册与登录分别进入独立路由，注册只建立账号及其默认配置。每个账号各自管理历史、能力配置和导览状态。服务端会话绑定账号 ID。已有安装从单账号结构迁移，并保留原有身份、配置版本、加密密钥与登录凭据。已有数据库的迁移先保留备份。本地部署按单个服务进程运行，多人身份集成走宿主提供的接口。

语义正确性通过对照段落评阅。引文存在、版本一致与可见性是程序能校验的条件。MCP 由操作者提供受信任的端点和凭据，远端的只读声明与本地允许的工具名共同决定可用范围。教程材料使用登记的来源版本，附件使用原始文件字节的 SHA-256 和保存的提取段落。

## 会话中的文件与回答版本

每个问题占据一个会话位置。重新生成关联最初的问题，成功后替换可见答复，反馈、引文和调用记录归属实际生成的版本。历史按问题分页。最近对话和历史页共用改名及删除操作。

文件随问题一次提交。文件名、内容指纹、可引用段落和原问题在一个事务内写入。取证范围由登录身份、会话、智能体权限及原问题的位置共同确定。Shell 接收由服务端解析出的段落，以标准输入交给指定的文本命令。文件名和模型输出都不能决定本机工作路径。

技能按目录发现 SKILL.md。内置技能进入新账号的初始配置，导入和编辑生成账号自己的配置。智能体选择已启用的技能后，由 AgentScope 在对话中按需读取。目录和工具设计参考了 [QwenPaw 的 Agents 实现](https://github.com/agentscope-ai/QwenPaw/tree/f22bbc8a3690a99ebacbb8e272d174520a1e0a19/src/qwenpaw/agents)。

## 行旁菜单与会话文件

历史行提供带焦点管理的浮层，使用触发按钮的实际位置定位。按钮与菜单间留 4 像素，下方空间不足时向上展开，手机抽屉移动和键盘弹出时重新定位。菜单、标题编辑和删除确认共用同一处，Esc 回到触发按钮。

目录、原文和附件沿用现有资料授权。生成的文本文件按账号和会话隔离，成功回答、文件版本和取证记录在同一个数据库事务中提交。回答上的下载对应当时的版本。重新生成加载原问题之前的工作文件并只读运行。Bash 把当前会话映射到 `/workspace`，将可见文件正文送入文本管道。网页浏览读取提问中指定的公开 HTTPS 页面及已呈现的同站链接，保留正文快照、行号和原始地址供回查。
