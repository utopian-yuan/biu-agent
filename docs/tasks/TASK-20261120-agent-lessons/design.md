# 设计

用「签收能否证明验收」贯穿取证过程。第一课写出同步的小循环，后续在合适处复用它，展示确定性模型决策、工具请求与业务回执的边界。涉及 SDK 行为的实验直接使用项目锁定的 AgentScope。课程专有数据保存在临时目录，时钟使用固定时间。

每章将运行命令、关键代码、预期现象、可改动的位置和业务实现放在一起。课程导航保留同源嵌入、工作台实操和可选评测入口。课程范围覆盖独立机制实验，工作台功能由原工作项维护。

前两课的深化沿用同一批到货和验收材料。第一课让手写循环与 AgentScope 共用教学模型、问题、工具和授权范围，从模型入口观测回执。第二课让目录和详情在同一套 SDK 工具中执行，在单独的内存数据库核对批准、重复提交和队列回读。回归测试从 README 所标的行号提取源码，逐段比对讲义中的 Python 摘录。

第三篇在两课中使用同一份公开虚构的项目备注。03 的内存待办用于拆开对象授权、原文批准和一次性消费，04 再以真实 AgentScope 事件和 SQLite 记录解释框架允许、业务授权和写入是否完成。原稿中的五张示意图放在对应代码旁。运行结果以项目锁定的 2.0.10 为准。

05 至 10 各选一种能独立核对的观察对象，包括展开后的技能正文、实际消息、可重新读取的偏好行、计划分钟、服务端接收的工具调用和父任务复读的原文。只读 API 实战沿用第二课的 SDK 调用入口，分别给读者看模型参数、HTTP 服务端身份和本轮证据。总览同时保留顺序学习和按问题选课两种入口。
