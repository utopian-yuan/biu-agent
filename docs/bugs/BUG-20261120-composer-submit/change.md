# 发送后输入框仍显示原消息

```json
{"id":"BUG-20261120-composer-submit","type":"bug","status":"in_progress","owner":"","created":"2026-11-20","updated":"2026-11-20"}
```

用户在材料工作台发送问题和附件后，聊天区已经出现问题，输入框仍显示原文及可移除的附件。关联[工作台附件交互 AC13](../../features/FEAT-20261120-assistant-workspace/change.md)。

| 编号 | 验收条件 |
| --- | --- |
| AC1 | 点击发送或按回车时，问题和附件名在消息区出现一次，输入框立即清空。只发附件时显示默认问题。 |
| AC2 | 等待回答时可以写下一条草稿，即使文字相同也会保留。重新生成既有回答会保留输入框里的文字和附件。 |
| AC3 | 提交被拒绝时能找回原文和原文件。已经写了下一问时，两份草稿都能取回。重新连接后同一请求只产生一条消息。 |

本次交付为本地工作台行为修复。人工验收人待认领。
