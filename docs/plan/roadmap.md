# 工作台路线图

| 阶段 | 可观察的交付结果 |
| --- | --- |
| 账号入口 | 注册成功回到登录页，用密码进入本人的工作台 |
| 一轮材料对话 | 列授权目录，按段取证，回答可回查文件与版本 |
| 权限与历史 | 账号之间隔离，收窄资料后新轮次按新权限取证 |
| 接入真实系统 | 替换一个只读来源，以同一组问题核对出处和权限 |

工程入口与数据流见[实施计划](PLAN-20261120-first-release.md)。本地实测和人工验收状态见[工作项](../features/FEAT-20261120-assistant-workspace/README.md)。
