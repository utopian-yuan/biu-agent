# 架构边界

工作台使用同一份聊天前端。独立启动时由材料宿主管理注册、登录、配置和来源；集成到已有系统时可由宿主提供身份、工具及确认操作。[装配入口](../../src/biu_agent/app.py)

| 部分 | 负责的内容 |
| --- | --- |
| 本地账号与配置 | 注册写入账号及其默认能力，登录签发与账号绑定的会话。账号之间隔离聊天、模型与 MCP 凭据、智能体及导览状态。[账号](../../examples/tickets/accounts.py) |
| 材料适配 | 组合部署范围、账号与智能体的授权，在读取时校验段号并记录文件版本。[工作台装配](../../examples/tickets/workspace.py) |
| 核心 | 处理会话、幂等请求、工具预算、权限变更、流式消息和同源嵌入。宿主可按需要提供业务写入处理器。[核心目录](../../src/biu_agent) |
| 可选观测 | 在本地记录轮次、模型和工具关系。外部链路导出由部署者配置。[Langfuse](../../integrations/langfuse/README.md) |

设计决定与可复验结果见[工作台四件套](../features/FEAT-20261120-assistant-workspace/README.md)。
