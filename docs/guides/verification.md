# 文档核对与交接

从仓库根目录运行 `git status --short --branch --untracked-files=all` 和 `git rev-parse --short HEAD`，记录当前分支、基线及本地新增文件。`git diff --check` 可以检查已跟踪的工作区差异，新文件也要核对内容和空白。

1. 从仓库首页打开文档中心，从中心定位目标工作项。核对目录名、`change.md` 的 JSON ID、类型、状态和验收条件。
2. 从任务行、变更日志沿证据链接回到相同版本。检查 Markdown 相对链接、标题锚点、目录大小写和客户端规则引用在当前工作区可解析。
3. 对照文件清单区分已有产物与拟建路径。公开页面和示例仅使用可公开信息，确认样本、图片说明和追踪记录均符合[协作约定](../../AGENTS.md)。
4. 在 `evidence.md` 追加本次环境、步骤、实测结果和覆盖边界。仅改文档时记录静态核对，涉及运行行为时补相应的运行证据。
